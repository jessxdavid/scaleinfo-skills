# Hooks and batch variation

## The title hook rule

Every script gets a **title hook** — roughly **8 words** of on-screen text that **matches the
opening spoken line.**

- It is the same words they are about to hear. Not a summary of the ad, not a caption, not a
  headline about the ad.
- It leaves out the "how". The spoken hook opens a loop; the title hook must not close it.
- It goes on screen from frame one.

Output shape, both modes:

```
TITLE HOOK: [~8 words, on-screen text matching the opening line]

[Full script — ready to record]
```

Test it like this: read the title hook, then read the first spoken sentence. If they are not
recognisably the same claim, rewrite the title hook — never the other way round.

---

## Hook formulas that work

- "Why is nobody talking about [interesting claim]?"
- "If you can [relatable skill], you can [desirable outcome]"
- "[Common belief] is a massive scam"
- "I [hated/quit/escaped] [pain point] and here's what happened"
- "While you're [their situation], there are people [better situation]"

These are the Mode 1 / B2C curiosity openers. In Mode 2 the hook is the **offer itself** — the
guarantee or bold claim in the first 5 seconds, with the ICP named in the same breath. See
`b2b-formulas.md` for how each formula opens.

## Hook rules

- **Talk about them, not you.** Use the words they would use.
- **Open a loop** — give just enough to create curiosity, never the answer.
- **Specific over vague** — "$31,200 across 26 accounts", not "good money".
- **Contrarian / pattern-interrupt framing beats polished claims.**
- **It must not feel like an ad** — casual, spontaneous, like talking to a mate.
- **One idea per ad.** If it needs a second breath to explain, it is two ads.

The first 3–5 seconds is the whole hook window. In B2C the hook lands in the **first 3 seconds**.

## Batch variation rules

When scripting a batch (5–10 B2B, 8–10 B2C):

1. Each ad gets a unique angle and a unique hook.
2. Vary the formulas across the batch — all five in B2B, all four angles in B2C.
3. Rotate which case study you lead with.
4. **Mode 1:** each ad gets its own unique tracking keyword.
5. **Mode 2:** test different guarantee framings.
6. Include at least one ultra-short ad (20–30s) per batch.

> **Never run the same hook across a batch.** The hook is the variable being tested. If all ten
> ads open the same way, you have run one test ten times and learned nothing.

Vary the hook *formula* too, not just the wording. Ten variations of "Why is nobody talking
about..." is still one test.

---

## Horizontal scaling — when an ad wins

Keep the angle identical and vary **one thing at a time.** Create 3–5 variations of the winner:

- **Same script, different hook** — keep the body, write 3 new opening lines.
- **Same formula, different case studies** — swap in fresh client results.
- **Same angle, different length** — cut a 45s and a 90s version.
- **Mode swap** — turn a winning Mode 2 funnel ad into a Mode 1 version, or the reverse. If you
  do this, the CTA changes with it. A funnel ad wearing a "comment KEYWORD" CTA is broken.

Update the title hook whenever the opening line changes. A new hook with the old title hook on
screen breaks the match rule above.

**Creative is consumable.** Add 3–5 new ads every 2 weeks regardless of how well the current
batch is performing.
